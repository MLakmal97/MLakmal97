# 📚 Learning Philosophy

I don't want to learn cybersecurity only by memorizing tools or commands.

For each practical lab, I try to understand:

```text
What is the vulnerability?
        ↓
Why does it exist?
        ↓
How can it be discovered?
        ↓
How can it be exploited?
        ↓
What is the attack path?
        ↓
What is the security impact?
        ↓
How can it be detected?
        ↓
How can it be mitigated?
        ↓
How would this appear in a real enterprise?
```

This approach helps me connect **offensive security, defensive security, and infrastructure engineering**.
